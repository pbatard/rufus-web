Rufus

सोप्या पद्धतीने बूट करण्यायोग्य USB ड्राइव्ह तयार करा

 

रुफस (Rufus) ही एक युटिलिटी आहे जी USB की/पेनड्राइव्ह, मेमरी स्टिक इत्यादींसारख्या बूट करण्यायोग्य USB फ्लॅश ड्राइव्हचे स्वरूपण व निर्मिती करण्यात मदत करते.

हे विशेषतः खालील प्रकरणांमध्ये उपयुक्त ठरू शकते:

  • तुम्हाला बूट करण्यायोग्य ISO (Windows, Linux, UEFI, इत्यादी) पासून USB इन्स्टॉलेशन मीडिया तयार करणे आवश्यक आहे.
  • तुम्हाला अशा प्रणालीवर काम करावे लागेल ज्यावर कोणतीही ऑपरेटिंग सिस्टम (OS) इन्स्टॉल केलेली नाही
  • तुम्हाला DOS मधून BIOS किंवा इतर फर्मवेअर फ्लॅश करावे लागेल
  • तुम्हाला एखादे लो-लेव्हल युटिलिटी चालवायचे आहे

आकाराने लहान असूनही, रुफस तुम्हाला आवश्यक असलेल्या सर्व गोष्टी पुरवतो!

या पृष्ठाच्या तळाशी रुफस द्वारे समर्थित ISOs ची एक अपूर्ण (सर्वसमावेशक नसलेली) यादी देखील दिली आहे. (1)

ज्या अनुवादकांमुळे रुफस (Rufus) आणि हे वेबपेज विविध भाषांमध्ये अनुवादित करणे शक्य झाले, त्यांचे आभार मानण्याची ही संधी मी घेत आहे. जर तुम्हाला रुफस (Rufus) तुमच्या स्वतःच्या भाषेत वापरता येत असेल, तर तुम्ही नक्कीच त्यांचे आभार मानले पाहिजेत!

एक्झिक्युटेबल डाउनलोड करा आणि ते चालवा – यासाठी इन्स्टॉलेशनची आवश्यकता नाही.

एक्झिक्युटेबलवर डिजिटल स्वाक्षरी केलेली आहे आणि त्या स्वाक्षरीमध्ये खालील गोष्टी नमूद केलेल्या असाव्यात:

  • "Akeo Consulting" (v1.3.0 किंवा त्यानंतरची आवृत्ती)
  • "Pete Batard - Open Source Developer" (v1.2.0 किंवा त्यापूर्वीची आवृत्ती)

DOS समर्थनाबाबतच्या नोंदी:

जर तुम्ही DOS बूट करण्यायोग्य (bootable) ड्राइव्ह तयार केला आणि नॉन-यूएस (non-US) कीबोर्ड वापरला, तर रुफस (Rufus) तुमच्या सिस्टमच्या लोकेलनुसार (locale) कीबोर्ड लेआउट निवडण्याचा प्रयत्न करेल.

ISO समर्थनाबाबतच्या नोंदी:

रुफस (Rufus) ची v1.1.0 आणि त्यानंतरच्या सर्व आवृत्त्या ISO इमेज (.iso) वापरून बूट करण्यायोग्य USB तयार करण्याची सुविधा देतात.

भौतिक डिस्क किंवा फाइल्सच्या संचापासून ISO इमेज तयार करणे खूप सोपे आहे; यासाठी InfraRecorder किंवा CDBurnerXP सारख्या मोफत उपलब्ध असलेल्या CD बर्निंग ॲप्लिकेशनचा वापर करता येतो.

सतत विचारले जाणारे प्रश्न (FAQ)

रुफस (Rufus) बाबत वारंवार विचारले जाणारे प्रश्न (FAQ) येथे (इंग्रजीमध्ये) उपलब्ध आहेत.

अभिप्राय देण्यासाठी, त्रुटी (bug) कळवण्यासाठी किंवा सुधारणेची विनंती करण्यासाठी, कृपया GitHub वरील issue tracker चा वापर करा. किंवा तुम्ही ई-मेल पाठवू शकता.

परवाना

GNU जनरल पब्लिक परवाना (GPL) आवृत्ती ३ किंवा त्यानंतरची आवृत्ती.
GPLv3 परवान्याचे पालन करण्याच्या अटीवर, तुम्ही हे सॉफ्टवेअर वितरित करण्यास, त्यात बदल करण्यास किंवा अगदी त्याची विक्री करण्यासही मुक्त आहात.

रुफस (Rufus) ची निर्मिती MinGW32 वातावरणाचा वापर करून, त्याच्या सार्वजनिक स्रोतापासून पूर्णपणे पारदर्शक पद्धतीने केली जाते.

    • Improve the guards for using the "silent" Windows installation option.
    • Improve the ability to cancel during write retries.
    • Improve progress reporting for compressed image extraction.
    • Fix unrestricted XML entity expansion and integer overflow in ezxml parser (courtesy of Eric Sadowski).
    • Fix "silent" Windows installation failing at 75% in most cases.

    • Fix first WUE option always being checked by default.
    • Fix an infinite loop when using Windows ISOs that contain multiple WIMs.

देणग्या

मला याबद्दल वारंवार विचारले जात असल्याने, सांगू इच्छितो की या पृष्ठावर देणगीचे कोणतेही बटण नाही.

याचे मुख्य कारण म्हणजे, मला असे वाटते की देणगीची पद्धत सॉफ्टवेअरच्या विकासाला खरोखर मदत करत नाही; आणि त्याहून वाईट म्हणजे, ज्या वापरकर्त्यांनी देणगी न देण्याचा निर्णय घेतला आहे, त्यांच्या मनात ती अपराधीपणाची भावना निर्माण करू शकते.

तुमचा खूपच आग्रह असेल, तर तुम्ही Free Software Foundation ला देणगी देऊ शकता; कारण रुफस (Rufus) सारखे सॉफ्टवेअर शक्य होण्यामागे त्यांचाच मुख्य वाटा आहे.

असो, या छोट्याशा उपक्रमाबद्दल तुम्ही दाखवत असलेला सातत्यपूर्ण पाठिंबा आणि उत्साह याबद्दल आभार मानण्याची ही संधी मी घेतो; तुमच्या या सहकार्याची मी मनापासून कदर करतो!

पण कृपया 'रुफस' (Rufus) वापरताना कोणत्याही प्रकारचा संकोच किंवा अपराधीपणाची भावना बाळगू नका – कारण त्यासाठी आर्थिक योगदान देण्याची तुम्हाला कधीच गरज पडणार नाही!
