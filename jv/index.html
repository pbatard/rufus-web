Rufus

Gawe bootable USB drive nganngo coro seng gampang

 

Rufus ki sarana seng mbantu format karo nggawe USB flash drive seng iso di-boot, koyo flashdisk, memori stik, sak piturute.

Iso digunakne utamane kanggo kasus neng ngisor iki:

  • nggawe media instalasi USB seko ISO bootable (Windows, Linux, UEFI, sak piturute.)
  • nggarap sistem seng ora diinstal OS
  • flash BIOS utowo perangkat firmware liyane teko DOS
  • pengen jalanke low-level utility

Senajan ukurane cilik, Rufus nyediakne kabeh seng sampeya butuhne!

Daftar ISO seng didukung Rufus yo disediakne neng bagian ngesor halaman iki. (1)

Penggunaan

Unduh executable e terus jalanke iku – ora perlu di pasang.

Executable e wes di sign secoro digital karo tanda tangan kudu nyatakne:

  • "Akeo Consulting" (v1.3.0 utowo lebih)
  • "Pete Batard - Open Source Developer" (v1.2.0 utowo sebelume)

Catetan nggo dukungan DOS:

Nek Sampeyan nggawe drive bootable DOS gek nggunakne keyboard non-US, Rufus bakal milih toto letak keyboard sesuai kambi lokasi sisteme Sampeyan.

Catetan nggo dukungan ISO:

Kabeh versi Rufus kawet v1.1.0 mungkinke nggawe USB bootable teko gambar ISO (.iso).

Nggawe gambar ISO teko disk fisik utowo teko sak set file kui gampang, lewat aplikasi pembakaran CD, koyo to InfraRecorder or CDBurnerXP.

Aku sering di tekoni perkoro sumbangan, tak tegeske neng halaman iki ora enek tombol sumbangan.

Alesan utamane kui korno aku ngeroso sistem donasi ora nggawe pengembangan priranti lunak luweh apik utowo luweh elek, malah iso ngekei roso bersalah kanggo pengguna seng ora nyumbang.
