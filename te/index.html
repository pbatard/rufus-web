Rufus

బూటబుల్ USB డ్రైవ్‌లను సులభమైన మార్గంలో సృష్టించండి

 

రూఫస్ అనేది USB కీలు/పెండ్‌రైవ్‌లు, మెమరీ స్టిక్‌లు మొదలైన బూటబుల్ USB ఫ్లాష్ డ్రైవ్‌లను ఫార్మాట్ చేయడంలో మరియు సృష్టించడంలో సహాయపడే యుటిలిటీ.

ఇది సందర్భాలలో ముఖ్యంగా ఉపయోగకరంగా ఉంటుంది:

  • మీరు బూటబుల్ ISOల నుండి USB ఇన్‌స్టాలేషన్ మీడియాను సృష్టించాలి (Windows, Linux, UEFI, మొదలైనవి)
  • మీరు OS ఇన్‌స్టాల్ చేయని సిస్టమ్‌లో పని చేయాలి
  • మీరు DOS నుండి BIOS లేదా ఇతర ఫర్మ్‌వేర్‌ను ఫ్లాష్ చేయాలి
  • మీరు తక్కువ-స్థాయి యుటిలిటీని అమలు చేయాలనుకుంటున్నారు

దాని చిన్న పరిమాణం ఉన్నప్పటికీ, రూఫస్ మీకు అవసరమైన ప్రతిదాన్ని అందిస్తుంది!

రూఫస్ మద్దతు ఉన్న ISOల యొక్క సమగ్ర జాబితా కూడా ఈ పేజీ దిగువన అందించబడింది. (1)

వాడుక

DOS మద్దతుపై గమనికలు:

మీరు DOS బూటబుల్ డ్రైవ్‌ని సృష్టించి, US-యేతర కీబోర్డ్‌ని ఉపయోగిస్తే, రూఫస్ మీ సిస్టమ్ యొక్క లొకేల్ ప్రకారం కీబోర్డ్ లేఅవుట్‌ను ఎంచుకోవడానికి ప్రయత్నిస్తుంది.

ISO మద్దతుపై గమనికలు:

v1.1.0 నుండి రూఫస్ యొక్క అన్ని సంస్కరణలు ISO ఇమేజ్ (.iso) నుండి బూటబుల్ USBని సృష్టించడానికి అనుమతిస్తాయి.

భౌతిక డిస్క్ నుండి లేదా ఫైల్‌ల సెట్ నుండి ISO ఇమేజ్‌ని సృష్టించడం అనేది CD బర్నింగ్ అప్లికేషన్‌ని ఉపయోగించడం ద్వారా చాలా సులభం, అంటే ఉచితంగా లభించే InfraRecorder లేదా CDBurnerXP.

లైసెన్స్

GNU జనరల్ పబ్లిక్ లైసెన్స్ (GPL) వెర్షన్ 3 లేదా తదుపరిది.
మీరు GPLv3 లైసెన్స్‌ను గౌరవించినంత వరకు, సాఫ్ట్‌వేర్‌ను పంపిణీ చేయడానికి, సవరించడానికి లేదా విక్రయించడానికి కూడా మీకు స్వేచ్ఛ ఉంది.

రూఫస్ పబ్లిక్ సోర్స్ నుండి MinGW32 పర్యావరణాన్ని ఉపయోగించి 100% పారదర్శక పద్ధతిలో ఉత్పత్తి చేయబడింది.

చేంజ్లాగ్

  • వెర్షన్ 4.9 (2025.06.15) [BUGFIX RELEASE]
    • Fix downloads from https://rufus.ie no longer working due to recent GitHub server changes
    • Fix unofficial Windows ISOs, with single index WIMs, not presenting the WUE dialog

    • Note: The GitHub issue mentioned above means that NONE of the existing versions of Rufus are able to automatically detect and update to the 4.9 release.
    You MUST upgrade to Rufus 4.9 manually, even if you have check for updates enabled... 😢

  • వెర్షన్ 4.8 (2025.06.11)
    • Switch to wimlib for all WIM image processing:
      • Greatly speeds up image analysis when opening Windows ISOs
      • Can speed up Windows To Go drive creation (But won't do miracles if you have a crap drive)
      • Might help with Parallels limitations on Mac (But Rufus on Parallels is still unsupported)
      • Enables the splitting of >4GB files with Alt-E (But still WAY SLOWER than using UEFI:NTFS)
    • Switch to using Visual Studio binaries everywhere, due to MinGW DLL delay-loading limitations
    • Add more exceptions for Linux ISOs that restrict themselves to DD mode (Nobara, openSUSE, ...)
    • Improve reporting of UEFI bootloaders in the log, with info on the Secure Boot status
    • Fix an issue with size limitations when writing an uncompressed VHD back to the same drive
    • Fix a crash when opening the log with the 32-bit MinGW compiled version
    • Fix commandline parameters not being forwarded to original Windows setup.exe

  • ఇతర సంస్కరణలు

విరాళాలు

నేను దీని గురించి తరచుగా అడుగుతున్నాను కాబట్టి, ఈ పేజీలో నో విరాళం బటన్ ఉంది.

ప్రధాన కారణం ఏమిటంటే, విరాళం వ్యవస్థ సాఫ్ట్‌వేర్ అభివృద్ధికి సహాయం చేయదని మరియు అధ్వాన్నంగా విరాళం ఇవ్వకూడదని ఎంచుకునే వినియోగదారులకు అపరాధ భావన కలిగించవచ్చని నేను భావిస్తున్నాను.

మీరు నిజంగా పట్టుబట్టినట్లయితే, మీరు ఎల్లప్పుడూ ఉచిత సాఫ్ట్‌వేర్ ఫౌండేషన్కి విరాళం ఇవ్వవచ్చు, ఎందుకంటే రూఫస్ వంటి సాఫ్ట్‌వేర్ సాధ్యమయ్యే ప్రధాన కారణం.

ఏమైనప్పటికీ, ఈ చిన్న కార్యక్రమం గురించి మీ నిరంతర మద్దతు మరియు ఉత్సాహానికి ధన్యవాదాలు చెప్పడానికి నేను ఈ అవకాశాన్ని ఉపయోగించుకుంటాను: ఇది చాలా ప్రశంసించబడింది!

కానీ దయచేసి రూఫస్‌కు ఆర్థికంగా సహకరించనందుకు ఎలాంటి అపరాధభావం లేకుండా ఉపయోగించడాన్ని సంకోచించకండి – మీరు ఎప్పటికీ చేయకూడదు!
