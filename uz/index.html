Rufus

Yuklanuvçi USB-disklarni yaratişning eng oson yöli

 

Rufus — bu USB fleşkalar va xotira kartalarini formatlaş hamda ularni yuklanuvçi diskka aylantiriş uçun möljallangan qulay dasturdir.

Rufus quyidagi holatlarda juda qöl keladi:

  • Yuklanuvçi ISO tasvirlaridan (Windows, Linux, UEFI va h.k.) örnatuvçi USB taşuvçilar yaratiş kerak bölganda
  • Operatsion tizim örnatilmagan kompyuterda işlaşingiz kerak bölganda
  • DOS muhiti orqali BIOS yoki boşqa mikrodasturni yangilaş kerak bölganda
  • Quyi darajali (low-level) tizim utilitalasini işlatmoqçi bölsangiz

Hajmi kiçik bölişiga qaramay, Rufus sizga kerakli barça imkoniyatlarni taqdim etadi!

Uşbu sahifaning pastki qismida Rufus qöllab-quvvatlaydigan ISO tasvirlarining (barçasi bölmasa-da) asosiy röyxati keltirilgan. (1)

Foydalaniş

Faylni yuklab oling va işga tuşiring — dasturni örnatiş talab etilmaydi.

Dasturning bajariladigan fayli (executable) raqamli imzolangan bölib, imzoda quyidagilar körsatilgan:

  • "Akeo Consulting" (v1.3.0 yoki undan keyingi)
  • "Pete Batard - Open Source Developer" (v1.2.0 yoki undan oldingi)

DOS qöllab-quvvatlanişi böyiça izohlar:

Agar siz DOS yuklanuvçi disk yaratsangiz va inglizça (AQŞ) bölmagan klaviaturadan foydalansangiz, Rufus tizimingiz lokaliga qarab klaviaturani tanlaşga urinib köradi.

ISO qöllab-quvvatlanişi böyiça izohlar:

Rufusʼning v1.1.0 versiyasidan boşlab barça versiyalari ISO tasvirlardan (.iso) yuklanuvçi USB-disk yaratiş imkonini beradi.

Jismoniy diskdan yoki bir neçta fayllardan ISO tasvirini yaratiş judayam oson. Buning uçun mutlaqo bepul taqdim etiladigan InfraRecorder yoki CDBurnerXP kabi CD yoziş dasturlaridan foydalanişingiz mumkin.

Tez-tez söraladigan savollar (FAQ)

Rufus haqida köp beriladigan savollar bilan BU YERDA tanişişingiz mumkin.

Fikr bildiriş, xatoliklar haqida xabar beriş yoki yangi funksiya taklif qiliş uçun GitHubʼdagi muammolarni kuzatiş tizimidan foydalaning. Şuningdek, elektron poçta yuborişingiz ham mumkin.

Özgarişlar röyxati

  • Versiya 4.15 (2026.06.30)
    • Add RISC-V 64 support to UEFI:NTFS.
    • Improve the guards for using the "silent" Windows installation option.
    • Improve the ability to cancel during write retries.
    • Improve progress reporting for compressed image extraction.
    • Fix unrestricted XML entity expansion and integer overflow in ezxml parser (courtesy of Eric Sadowski).
    • Fix "silent" Windows installation failing at 75% in most cases.
    • Fix a crash during boot when using UEFI:NTFS on Snapdragon X based ARM64 platforms.
    • Fix first WUE option always being checked by default.
    • Fix an infinite loop when using Windows ISOs that contain multiple WIMs.
    • Fix "Enable runtime UEFI media validation" checkbox not always being properly enabled.
    • Other WUE improvements/fixes for OneDrive removal and username validation (with thanks to @christian8641).
